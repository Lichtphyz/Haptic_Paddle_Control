# Haptic_Paddle_Control
2-mode Teleoperation of a 1-D PID system using a haptic feedback paddle system.

C++ code run on 2 serial-connected Arduino microcontrollers (ES32 & R3).

Key Files:
- Haptics_final_project_v4.ino : Haptic Control file, written to run on Artudino ES32 microcontroller, created for this project
- Haptics_final_Project_Turntable_6_1_final.ino : Rotational Platform PID code, repurposed from an existing system.  Written for Arduino R3 microcontroller.
